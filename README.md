# Interval Timer

Simple interval timer for Linux built with Python and Tkinter.

## Requirements

* Python 3
* Tkinter
* Linux

On Arch Linux:

```bash
sudo pacman -S tk
```

## Installation

```bash
git clone <repository-url>
cd tkinter

python -m venv .venv
source .venv/bin/activate

python intro.py
```
